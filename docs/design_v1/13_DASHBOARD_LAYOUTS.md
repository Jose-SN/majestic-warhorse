# Dashboard Layout System

**Purpose:** Create analytics and business dashboards.

---

# Dashboard Structure

```
Header
↓
Summary Metrics
↓
Charts
↓
Tables
↓
Activity
```

---

# Dashboard Grid

| Viewport | Columns |
|----------|---------|
| Desktop | 12 columns |
| Tablet | 8 columns |
| Mobile | 1 column |

---

# Metric Cards

**Grid:** 4 columns

**Each card:**

| Property | Value |
|----------|-------|
| Height | 140–180px |
| Padding | 24px |

**Contains:**

- Label
- Value
- Trend
- Icon

---

# Chart Sections

| Region | Columns |
|--------|---------|
| Large chart | 8 columns |
| Secondary information | 4 columns |

---

# Activity Feed

| Property | Value |
|----------|-------|
| Width | 4 columns |
| Items | Cards |
| Row height | 64px |

---

# Dashboard Rules

**Prioritize:**

1. Important numbers
2. Trends
3. Actions
4. Details

---
