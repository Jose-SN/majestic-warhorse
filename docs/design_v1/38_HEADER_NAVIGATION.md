# Header Navigation System

## Purpose

The header provides global navigation, quick actions and user context.

---

# Desktop Header

| Property | Value |
|----------|-------|
| Height | 64px |
| Background | Surface with blur |
| Border | Bottom 1px `rgba(255,255,255,0.1)` |

---

# Layout

| Side | Content |
|------|---------|
| Left | Brand / Logo |
| Center | Optional search |
| Right | Actions · Notifications · Wallet · Profile |

---

# Logo

| Property | Value |
|----------|-------|
| Size | 32–40px |
| Clear space | 16px minimum |

---

# Search

| Property | Value |
|----------|-------|
| Width | 320px |
| Height | 40px |
| Position | Center preferred |

---

# Action Buttons

| Property | Value |
|----------|-------|
| Icon size | 20–24px |
| Touch target | 44px |

---

# Profile Menu

**Contains:**

- Avatar
- Name
- Role
- Settings
- Logout

---

# Sticky Behaviour

Header remains visible during scrolling.

---

# Mobile

**Height:** 56px

**Structure:**

- Back button
- Title
- Actions

**Maximum:** 2 actions

---

# Rules

**DO:**

- Keep header simple
- Prioritize frequent actions

**DON'T:**

- Add too many buttons
- Put secondary navigation here
