# Detail Page Layout

**Used for:**

- Users
- Products
- Transactions
- Projects
- Records

---

# Structure

```
Header
↓
Summary
↓
Tabs
↓
Content
```

---

# Header

**Contains:**

- Avatar / Icon
- Title
- Status
- Actions

---

# Summary

**Cards:** 3–4 metrics

| Viewport | Layout |
|----------|--------|
| Desktop | Horizontal |
| Mobile | Vertical |

---

# Tabs

| Property | Value |
|----------|-------|
| Height | 48px |
| Active | Orange underline |

---

# Content

**Use:**

- Cards
- Tables
- Timeline
- Activity

---

# Timeline Pattern

Blockchain style:

- Vertical line
- Orange nodes
- Connected events

---

# Rules

Never overload detail pages.

Progressive disclosure is required.
