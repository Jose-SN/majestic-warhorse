# Shadows And Glow

This system avoids normal black shadows.

Use colored light.

---

## Orange Glow

```css
rgba(247, 147, 26, 0.5)
```

## Gold Glow

```css
rgba(255, 214, 0, 0.3)
```

---

## Usage

| Element | Treatment |
|---------|-----------|
| Buttons | strong glow |
| Cards | soft glow |
| Hover | increase glow |

---

## Never

Use heavy black shadows.
