# Form System

## Philosophy

Forms should feel simple and guided.

---

# Layout

| Viewport | Columns |
|----------|---------|
| Desktop | Maximum 2 columns |
| Mobile | Single column |

---

# Field Spacing

| Context | Value |
|---------|-------|
| Between fields | 24px |
| Between sections | 40px |

---

# Validation

**Validate:** After interaction

**Never:** Show errors immediately

---

# Required Fields

Use `*`

Provide explanation.

---

# Submit

| Viewport | Alignment |
|----------|-----------|
| Desktop | Right aligned |
| Mobile | Full width |
