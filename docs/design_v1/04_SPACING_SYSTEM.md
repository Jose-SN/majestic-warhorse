# Spacing System

The entire product follows an 8 point grid.

**Allowed spacing:**

- 4
- 8
- 12
- 16
- 24
- 32
- 40
- 48
- 64
- 80
- 96

---

# Usage

| Context | Value |
|---------|-------|
| Card padding | 24px |
| Section spacing | 64–96px |
| Component gap | 16–24px |
| Page padding (desktop) | 32px |
| Page padding (mobile) | 16px |

---

# Rules

**Never use:**

- 13px
- 27px
- 35px

Random spacing destroys consistency.
