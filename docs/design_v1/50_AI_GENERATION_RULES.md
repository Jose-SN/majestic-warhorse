# AI UI Generation Rules

**Purpose:** Ensure AI-generated interfaces follow this design system.

---

# Before Creating UI

AI must check:

1. Layout rules
2. Design tokens
3. Component library
4. Responsive behaviour
5. Accessibility

---

# Visual Identity

Always maintain:

- Dark background
- Bitcoin orange accents
- Gold highlights
- Glass surfaces
- Technical premium feel

---

# Layout Rules

**Always:**

- Use 8pt spacing
- Use max width
- Use consistent alignment

**Never:** Create random layouts

---

# Components

AI must:

- Reuse existing components
- Create variants only when needed

**Never:** Create duplicate buttons / cards / forms

---

# Responsive Rules

| Viewport | Pattern |
|----------|---------|
| Desktop | Sidebar + content |
| Mobile | Drawer / bottom navigation |
| Tables | Convert or scroll |

---

# Code Rules

**Never generate:**

- Hardcoded colours
- Random spacing
- Inline styles everywhere
- Duplicate components

---

# Quality Checklist

Before output:

- Responsive
- Accessible
- Token based
- Consistent spacing
- Correct typography
- Correct states

---

# Final Rule

Generated UI should feel like Linear · Stripe · Vercel · GitHub · Coinbase

while preserving Bitcoin design language.
