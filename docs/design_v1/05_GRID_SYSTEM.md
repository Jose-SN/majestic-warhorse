# Grid System

## Desktop

- 12 column grid
- **Container:** 1280px max-width
- **Column gap:** 24px

## Tablet

- 8 column grid

## Mobile

- 4 column grid

---

# Layout Rules

Content should align vertically.

Cards should share:

- same left edge
- same spacing
- same width system

---

# Dashboard

**Preferred:** 12 columns

| Charts | 8 columns |
