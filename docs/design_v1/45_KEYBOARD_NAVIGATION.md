# Keyboard Navigation

## Required Keys

| Key | Action |
|-----|--------|
| Tab | Move forward |
| Shift + Tab | Move backward |
| Enter | Activate |
| Space | Toggle |
| Escape | Close |
| Arrow Keys | Navigate lists |

---

# Focus Order

Must follow visual order.

Never use random DOM order.

---

# Components

## Modal

| Event | Focus |
|-------|-------|
| Open | First element |
| Close | Return focus |

## Dropdown

| Key | Action |
|-----|--------|
| Arrow keys | Move selection |
| Enter | Select |
| Escape | Close |

## Tabs

| Key | Action |
|-----|--------|
| Arrow keys | Switch tabs |
| Enter | Activate |

## Tables

Keyboard sorting supported.

---

# Rules

Never create keyboard traps.

Never remove focus outlines.
