# Typography System

## Font Families

### Heading

**Family:** Space Grotesk

**Usage:**

- H1–H6
- Hero titles
- Section headings

### Body

**Family:** Inter

**Usage:**

- Paragraphs
- Forms
- Buttons

### Mono

**Family:** JetBrains Mono

**Usage:**

- Numbers
- Crypto values
- Addresses
- Technical data

**Body:** relaxed line-height
