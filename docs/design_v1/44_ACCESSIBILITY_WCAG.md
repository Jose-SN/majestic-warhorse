# Accessibility System

Version: 1.0

## Philosophy

Accessibility is not an optional feature.

Every user must be able to:

- Understand
- Navigate
- Interact
- Complete tasks

The system follows **WCAG 2.2 AA** principles.

---

# Perceivable

## Color Contrast

| Text | Minimum ratio |
|------|----------------|
| Normal | 4.5:1 |
| Large text | 3:1 |

---

# Never communicate only using color

**Bad:** Red = failed

**Good:** Red + Error icon + Message

---

# Text

**Minimum body:** 16px

Avoid tiny text for important information.

---

# Images

Every meaningful image requires: **alt text**

Decorative images: **empty alt**

---

# Operable

## Keyboard

Everything interactive must work using:

- Tab
- Enter
- Space
- Escape
- Arrow keys

---

# Focus

Every interactive element requires visible focus.

**Recommended:** 2px orange outline

---

# Touch

| Target | Size |
|--------|------|
| Minimum | 44×44px |
| Preferred | 48×48px |

---

# Understandable

Forms must provide:

- Labels
- Instructions
- Errors
- Success feedback

---

# Predictable Behaviour

Buttons should behave consistently.

Navigation should not change unexpectedly.

---

# Robust

**Support:**

- Screen readers
- Browser zoom
- Assistive technology

---

# Dark Theme

Ensure orange text, gold text, and muted text maintain contrast.
