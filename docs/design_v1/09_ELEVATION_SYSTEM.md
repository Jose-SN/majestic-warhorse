# Elevation System

Depth is created using:

1. Transparency
2. Blur
3. Glow
4. Borders

---

## Levels

| Level | Use |
|-------|-----|
| Level 0 | Background |
| Level 1 | Cards |
| Level 2 | Dropdowns |
| Level 3 | Dialogs |
| Level 4 | Floating elements |

---

## Glass Formula

| Property | Value |
|----------|-------|
| background | white 5% |
| backdrop blur | 16px |
| border | white 10% |
