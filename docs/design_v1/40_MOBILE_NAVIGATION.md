# Mobile Navigation System

## Philosophy

Mobile navigation should support one-hand usage.

---

# Bottom Navigation

Preferred for primary sections.

| Property | Value |
|----------|-------|
| Height | 64px |
| Items | Maximum 5 |

---

# Item

| Property | Value |
|----------|-------|
| Icon | 24px |
| Label | 12px |
| Touch area | 48px |

---

# Active State

| Property | Value |
|----------|-------|
| Icon | Bitcoin Orange |
| Indicator | Orange pill |

---

# Mobile Drawer

Used for secondary navigation.

| Property | Value |
|----------|-------|
| Width | 85% screen |
| Background | Surface |

---

# Gesture

**Support:**

- Swipe from edge
- Back gesture

---

# Floating Action Button

| Property | Value |
|----------|-------|
| Size | 56px |
| Position | Bottom right |
| Offset | 16px |

---

# Rules

**DO:**

- Keep primary actions reachable

**DON'T:**

- Hide important actions in menus
